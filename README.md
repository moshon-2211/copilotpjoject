# Wilderness Mountains

A responsive outdoor storefront landing page built with Next.js, React, Tailwind CSS, Framer Motion, and Lucide.

## Getting started

Requirements: Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Production

```bash
npm run build
npm start
```
